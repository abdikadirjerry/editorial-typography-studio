# Editorial Typography & Contrast Studio (`ts-editorial-typography-studio`)

An interactive modular type scale calculator, font pairing specimen sheet, and WCAG 2.1 color contrast workbench built with React, TypeScript, Vite, and Tailwind CSS featuring a Neo-Brutalist print magazine interface.

## Features

- **Modular Scale Engine:** Computes harmonic typographic steps across Minor Third, Major Third, Perfect Fourth, and Golden Ratio proportions.
- **WCAG 2.1 Contrast Auditing:** Real-time relative luminance calculation with AA and AAA compliance badges.
- **Interactive Broadsheet Specimen:** Click-to-edit headlines and body copy with one-click CSS custom property export.

## Setup & Running

```bash
cd ts-editorial-typography-studio
npm install
npm run dev
```
